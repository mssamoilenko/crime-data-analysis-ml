# Crime Data Analysis & Classification Using Machine Learning

### IT STEP Academy — Graduation Project

## Project Overview

This project explores crime-related data using Python and machine learning techniques.

The main objectives are to analyze patterns in the dataset, prepare data for modeling, and develop a classification model for predicting crime categories.

## Tools & Technologies

- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- XGBoost
- Optuna
- Jupyter Notebook

## Project Workflow

### 1. Exploratory Data Analysis
- Exploring dataset structure and feature distributions
- Investigating patterns in crime-related data
- Visualizing relationships between variables

### 2. Data Preprocessing
- Handling data quality issues
- Preparing numerical and categorical features
- Creating features for machine learning

### 3. Machine Learning
- Building a classification model using XGBoost
- Optimizing hyperparameters with Optuna
- Evaluating model performance using classification metrics

### 4. Model Evaluation
- Accuracy and F1-score
- Classification report
- Confusion matrix
- Feature importance analysis

## Project Files

The repository contains Jupyter Notebook files documenting the analysis and model development process.
